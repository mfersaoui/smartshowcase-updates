# Changelog — Smart Showcase Sensor

Déclaration de version pour le composant Sensor (contrôleur RP2040-Zero,
radar LD2410C ou PIR). Ce dossier est isolé du reste du dépôt
(`system-version.txt`, `promo-banner.json`, `README.md` à la racine
restent réservés à Smart Showcase Lite, inchangés).

`sensor/version.txt` contient uniquement la version courante publiée,
en texte brut (`MAJOR.MINOR.PATCH`). Les packages associés sont publiés
comme Releases GitHub avec un tag préfixé `sensor-v` (ex. `sensor-v1.0.1`),
pour ne jamais se confondre avec les tags de templates existants.

## 1.0.1

Version initiale publiée du composant Sensor.
